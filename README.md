# Лабораторная работа №2. Задача о назначениях (вариант 6)

Курс «Теория оптимизации. Линейное программирование», НИЯУ МИФИ.
Автор: Довгер Евгения Андреевна, группа Б24-507.

## Задача

Назначить 6 бригад на 6 объектов так, чтобы суммарное время работ было
минимальным. Каждая бригада идёт на один объект, на каждом объекте
работает одна бригада. Задача решается как задача линейного
программирования (солвер HiGHS через scipy.optimize.linprog).

Параметры варианта: N = 7, Q = 0, Y = 26, вариант 6, seed 10007.
Время работ - целые числа от 4 до 20 часов.

## Установка

Нужен Python 3.9 или новее.

    pip install -r requirements.txt

## Запуск

Всё считается одной командой из корня проекта:

    python src/main.py

Отдельные этапы можно запускать по файлам: generate_data.py, solve.py,
verify.py, greedy.py, scenarios.py, plots.py (из папки src).

## Структура

- data/times.csv - матрица времён (строки - бригады, столбцы - объекты)
- src/generate_data.py - генерация данных
- src/data_io.py - загрузка и проверка данных
- src/model.py - построение ЛП-модели
- src/solve.py - решение, статус, лог
- src/verify.py - независимая проверка решения
- src/greedy.py - жадная эвристика для сравнения
- src/scenarios.py - сценарии
- src/plots.py - схемы назначений
- src/main.py - запуск всего
- report/report.md - отчёт
- src/brute_force.py - полный перебор всех назначений (проверка единственности оптимума)
- src/integer_version.py - целочисленная версия (MILP), сравнение с LP
- src/formulations.py - формулировка узел-дуга, сравнение с прямой моделью
- src/animation.py - анимация роста нагрузки на базовые пары

## Результаты (папка results)

- assignment.csv - назначения базового сценария
- verification.txt - результаты проверки
- solver_log.txt - статусы солвера по всем сценариям
- scenarios.csv, scenario_assignments.csv - таблицы сценариев
- assignment_base.png, assignment_deficit.png, assignment_stress.png - схемы
- brute_force.txt - результат полного перебора
- lp_vs_milp.csv - сравнение LP и MILP
- formulations.csv, formulations_scaling.csv - сравнение двух формулировок

## Допущения

- Время работ не зависит от порядка выполнения и от других назначений.
- Вместо «самой загруженной дуги» закрывается самая критичная пара: та,
  закрытие которой сильнее всего увеличивает суммарное время.
- Решение получается целым без дополнительных условий, так как матрица
  ограничений задачи о назначениях обладает свойством целочисленности.
- При запуске main.py данные генерируются заново с тем же seed, поэтому
  правки в data/times.csv будут перезаписаны.
